TRACE-BE

Transparent Reporting and Accounting for the Built Environment

The TRACE-BE reporting framework is designed for studies that rely on two key components to model building material stocks: building inventory and material intensity data. The framework is built in a way to represent a building material stock study for a single time frame. For studies that assess stocks across multiple time steps to capture temporal dynamics, the framework should be applied separately for each time frame.
